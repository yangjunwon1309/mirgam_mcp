# Beacon 대시보드 UI 변경 명세

- 상단 DATA SOURCE를 농장, 제주 날씨, 데이터 서버의 폴더 탭으로 구성한다. 데이터 서버는 대시보드 영역 전체에서 열린다.
- 농장 화면의 Beacon 관리는 장치 상태와 작업을 보여주고, 오른쪽 버튼에서 체크인 장치 찾기와 장치 설정 팝업을 연다.
- Beacon 버튼은 밝은 배경에 진한 글씨 또는 진한 배경에 밝은 글씨를 사용하며, 선택·비활성·키보드 포커스를 구분한다.
- 농장 지도에는 등록된 Beacon의 metadata.location 좌표를 사용한다. 마커를 클릭하면 해당 장치의 데이터 서버로 이동한다.
- 데이터 서버는 농장·장치·종류로 탐색하고 검색 및 종류 필터를 제공한다. 탐색 목록과 미리보기 높이를 제한하고 각각 스크롤한다.
- 센서와 이벤트는 SQLite 기록을 파일 형식으로 표현하며, 이미지는 SSD에 저장된 원본을 보여준다. 표시 개수는 API의 최근 기록 제한을 따른다.
- Beacon 관리는 데이터 서버 옆의 별도 탭에서 농장을 선택해 연다. 위치 선택 시 농장 지도로 전환하고, 선택 또는 취소 후 Beacon 설정으로 복귀한다.
- 장치 추가 팝업은 체크인된 장치 목록을 선택하는 방식으로 제공하고, 장치 속성 팝업에는 식별 정보와 설정을 구분해 보여준다.
- 센서·이미지 폴더는 각각 열기/닫기를 지원하며, 지도 마커는 농장 화면이 등록 장치의 저장 좌표를 독립 조회해 표시한다.
