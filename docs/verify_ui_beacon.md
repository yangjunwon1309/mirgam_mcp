# Beacon UI 사람 검수

먼저 `bash docs/verify_ui_beacon.sh`를 실행하고 브라우저에서 `http://<Jetson IP>:3100`으로 접속합니다. 스크린샷은 `docs/_shots/<ID>_<폭>.png`로 보관합니다.

## 농장 회귀

- [ ] R1 농장 현황에서 농장을 만들고 경계를 저장한다. 저장된 지도에 경계가 보인다.
- [ ] R2 농장 설정에서 경로를 추가하고 삭제한다. 각각 지도에 반영된다.
- [ ] R3 지도 범위 준비 버튼을 누른다. 작업 진행 뒤 타일이 표시된다.
- [ ] R4 농장 현황과 Beacon의 농장 선택을 각각 바꾼다. 지도와 Beacon·데이터 서버가 같은 농장을 표시한다.

## Beacon

- [ ] B1 Beacon 탭의 요약 숫자와 카드 수를 비교하고 상태 필터를 누른다. 선택한 상태만 보인다.
- [ ] B2 카드를 열어 카운트다운이 매초 변하는지 본다. Esc로 닫으면 카드에 포커스가 돌아온다.
- [ ] B3 센서 읽기를 누른다. 작업 대기 후 체크인 결과가 완료로 바뀐다.
- [ ] B4 촬영 해상도를 SVGA로 바꾸고 촬영한다. 네트워크 요청에 `fs: SVGA`가 들어 있다.
- [ ] B5 오프라인 장치에서 센서 읽기를 누른다. 재연결 후 전달된다는 안내가 보인다.
- [ ] B6 추가 메뉴에서 10분간 자주 확인을 누른다. 다음 체크인 후 상태에 반영된다.
- [ ] B7 장치 추가를 열어 장치·수집 설정·지도 위치를 지정하고 저장한다. 카드가 표시된다.
- [ ] B8 장치 상세에서 절전을 누르고 이름을 잘못 입력한다. 확인 버튼이 비활성이다.
- [ ] B9 Beacon 서버를 중지한다. 연결 불가 안내와 저장된 카드가 보인다. 검수 후 재시작한다.
- [ ] B10 대시보드 폭 640px 이하에서 상세를 연다. 아래 시트처럼 보이며 조작 가능하다.

## 데이터 서버

- [ ] D1 장치 상세의 데이터를 누른다. 같은 장치의 데이터가 열린다.
- [ ] D2 센서 그래프에 마우스를 올리고 좌우 키를 누른다. 값과 시각이 바뀐다.
- [ ] D3 이미지를 열어 이전·다음 및 Esc를 사용한다. 이미지가 바뀌고 닫힌다.
- [ ] D4 체크인 결과별 상태를 확인한다. 정상·주의·오류가 구분된다.
- [ ] D5 작업의 JSON을 열고 닫는다. 요청과 결과를 확인할 수 있다.
- [ ] D6 CSV를 내려받아 연다. 표시된 행 수가 같고 한글이 정상이다.

## 삭제 시나리오

X1, X2, X4, X6을 각각 진행하기 **전과 후** 아래 읽기 전용 행 수 명령을 실행해 차이를 기록합니다.

```bash
cd ~/mirgam_mcp
 docker compose --env-file .env -f infra/compose.yaml exec -T api python -c 'import sqlite3; d=sqlite3.connect("file:/workspace/storage/state/mirgam.db?mode=ro",uri=True); print({t:d.execute("select count(*) from "+t).fetchone()[0] for t in ("sensor_readings","camera_assets","beacon_node_checkins","beacon_commands","beacon_data_deletions")})'
```

- [ ] X1 센서 3건을 선택해 삭제 확인한다. 즉시 숨겨지고 6초 후 요청 1회와 DB 3행 감소가 확인된다.
- [ ] X2 같은 절차에서 실행 취소한다. 삭제 요청 없이 행이 복구된다.
- [ ] X3 일부 행 선택 후 머리 체크박스를 확인한다. 일부 선택 표시와 보이는 행 전체 선택이 동작한다.
- [ ] X4 이미지 날짜 그룹을 선택해 삭제한다. 사본 파일·DB 행은 사라지고 `/mnt/nvme/beacon/images/`의 원본은 남는다.
- [ ] X5 기간 삭제에서 30일 이전을 선택한다. 사전 조회 건수와 실제 삭제 건수가 일치한다.
- [ ] X6 전체 삭제에서 장치 이름을 틀리게 입력한다. 버튼이 비활성이고, 정확한 이름에서만 활성이다.
- [ ] X7 진행 중 작업과 최신 체크인 선택을 시도한다. 체크박스가 비활성이다.
- [ ] X8 삭제 확인 후 6초 안에 API를 중단한다. 오류와 재시도 버튼이 뜨고 행이 복구된다. 검수 후 API를 재시작한다.
- [ ] X9 삭제 대기 중 탭을 이동한다. 타이머가 끝나면 확정된다. 다른 건을 대기 중 브라우저 탭을 닫으면 확정되지 않는다.
